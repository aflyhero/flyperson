### 春节前目标

执行率达到80%左右、没有伤病的前提下，争取：

- 体重约70–72公斤，即140–144斤；
- 腰围较启动日减少6–10厘米；
- 侧面小腹明显收紧，脸部和腰线更清楚；
- 胸肩、臀腿和核心形成基础力量；
- 每周完成3次力量训练，日均8000步左右；
- 建立不靠极端节食也能持续的饮食习惯。

17周内“小腹明显变小”是现实目标，但不承诺一定出现清晰六块腹肌。

### 四个关键数字

1. 每周力量训练3次；
2. 每天蛋白质120–140克；
3. 日均步数由6000逐步提高到8000–10000；
4. 每周体重平均下降约0.2–0.4公斤。

### 执行原则

- **每周三张训练券**：完整训练或8分钟保底训练都算一次，不死守固定星期。
- **不连续两次缺席**：没有完整时间就做保底版。
- **不靠挨饿**：每天三餐，先保证蛋白质和蔬菜，再控制总量。
- **看趋势，不看一天**：只比较7天平均体重和周腰围。
- **每两周才调整**：不给单日波动过度反应。

### 两周调整规则

- 体重缓慢下降、腰围缩小、训练稳定：保持；
- 体重不变但腰围缩小、动作进步：保持，这是身体重组；
- 体重和腰围连续两周都不变，且执行率≥80%：每天减少100–150千卡，或日均增加1500–2000步，二选一；
- 每周下降超过0.6公斤，并持续疲惫、明显饥饿或力量下降：每天增加100–200千卡；
- 执行率不足70%：先修复执行，不调整热量。

### 安全边界

出现胸痛、晕厥、异常气短、突发锐痛、明显肿胀或疼痛改变正常走路姿势时停止训练并考虑就医。关节刺痛、电击感、麻木或动作越来越失控，不属于“坚持一下就好”。
